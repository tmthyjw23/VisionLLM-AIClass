AI Building Vision Inspector

Class Practical #1 | UNKLAB

Mata Kuliah AI • Kolab: Informatika ↔ Arsitektur

Tujuan (Goals)

  1. Menguji kemampuan vision LLM mendeteksi objek interior.
  2. Membuat prompt efektif untuk material, kondisi, pencahayaan.
  3. Verifikasi manual (Ground Truth) vs Hasil AI.
  4. Menganalisis akurasi & limitasi LLM Vision.

Arsitek Sistem

Input: Gambar Interior → Prompt Builder (Structured/Arch/Generic) → LLM Vision (Gemini API) → Output JSON.
Ground Truth: Arsitek catat objek aktual sebelum LLM (Blind Pre-Inspect).
Verifikasi: Engine matching fuzzy + sinonim Indonesia → 4 Kategori: Correct/Missed/False/Misclassified.
Output: Dashboard Metrik + Export MD/CSV (10 Analisis Questions).

Alur Kerja Activity #1

  1. Input Citra: Unggah foto ruang kelas/koridor atau ambil via webcam.
  2. Ground Truth (Blind): Arsitek mencatat objek aktual, material, kondisi sebelum LLM dijalankan.
  3. Pilih Preset Prompt: Structured JSON (rekomendasi), Architectural, atau Generic.
  4. Jalankan Vision LLM: Kirim gambar ke Gemini API.
  5. Verifikasi & Export: Sistem klasifikasi otomatis + Export laporan Markdown/CSV untuk 10 Pertanyaan Analisis.

Flow Data & Verifikasi

[User Upload] → [DB: images] →
[Prompt Selection] →
[Vision API Call] → [DB: detections] →
[Verification Engine] (Fuzzy + Klub Sinonim) → [DB: verifications] →
[Dashboard] (4 KPI + Table per-ekselusif) →
[Export] (Markdown Laporan + CSV Dataset).

4 Kategori: Correct | Missed | False | Misclassified

10 Pertanyaan Analisis (Output Otomatis)

  • 1. Berapa banyak objek terdeteksi LLM?
  • 2. Apakah semua objects berhasil dideteksi?
  • 3. Ada Missing Detection?
  • 4. Ada False Detection?
  • 5. Ada Misclassification?
  • 6. Objek mudah dikenali? (Kontur jelas, skala besar).
  • 7. Objek sulit dikenali? (Kecil, terpasang rata dinding).
  • 8. Kualitas gambar memengaruhi hasil?
  • 8. Perubahan prompt memengaruhi hasil?
  • 9. Apa batasan LLM Vision?

Kesimpulan Diskusi

"LLM vision memiliki pemahaman semantik tinggi terhadap material & kerusakan bangunan, namun lemah pada objek kecil/terpasang rata (saklar, stopkontak) dan bergantung pada resolusi/pencahayaan gambar."
